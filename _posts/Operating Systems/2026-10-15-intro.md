# Core Functionalities of Operating Systems

![](/assets/img/OS/intro/os_0.png)

## Basic Structure of an Operating System
![](/assets/img/OS/intro/os_1.png)

**User processes** process the users’ jobs. For example: `chrome, vscode,...`

**System processes** provide services of the operating system. For example: `Init/Systemd, sshd, systemd-journald, ...`

The **operating system core/kernel** contains all components of the operating system, which are not implemented as system processes. For example: `RAM or CPU manager.`


## Batch Processing
Batch processing is a method of grouping multiple tasks together and processing them automatically in a sequence, without requiring user interaction during execution.

![](/assets/img/OS/intro/batch_processing.png)

**Advantages:** Batch processing speeds up overall task processing through automation.

**Disadvantages:** CPU usage is still not optimized.

- Why?

        When a program has to wait for input/output (I/O) operations, such as reading data from a storage device, the CPU may do nothing.

        This phenomenon is called CPU idle.

## Spooling

![](/assets/img/OS/intro/spooling.png)

Image above is a model that uses frontend and backend computing to reduce the slow I/O workload that the mainframe computer has to perform directly.

```
Practical example: You want to print 20 documents.

You don't need to wait for the printer to finish the first document before sending the second.
```

Instead:
1. Documents are placed in a print queue.

2. The system manages the queue.

3. The printer processes them sequentially.

4. The CPU can then continue performing other tasks.

## Multitasking

Multitasking allows multiple processes to execute concurrently, either truly in parallel on multiple CPU cores or quasi-parallel on a single CPU core.

### Time-sharing
Time-sharing distributes CPU time among multiple processes or users using time slices. Its main objective is the fair distribution of computing time.

### What is the difference between Multitasking and Time-sharing?

Multitasking describes the concurrent execution of multiple processes, while time-sharing describes the distribution of CPU time among processes using time slices.

![](/assets/img/OS/intro/multitasking.png)

The computing time is distributed via time slices.

**Memory Protection:** Ensure that Process A cannot access or modify Process B's private memory area without authorization.

**Scheduling:** The operating system must decide who gets CPU service first, for how long, and when to resume.

**Swapping:** When there isn't enough RAM for all processes, the operating system can move some data between RAM and the HDD/SSD.

**File Systems:** The operating system needs to manage the simultaneous use of the file system by multiple processes.
