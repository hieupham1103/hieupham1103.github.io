# Assets Directory

## Images (`/assets/img/`)

Place your images here:
- Profile photo
- Blog post images
- Project screenshots
- Diagrams and figures

Example usage in markdown:
```markdown
![Alt text](/assets/img/your-image.jpg)
```

## CV Files (`/assets/cv/`)

Place your PDF CV here for download:
- `CV_Pham_Dinh_Trung_Hieu.pdf`

The download button on the CV page links to:
```
/assets/cv/CV_Pham_Dinh_Trung_Hieu.pdf
```
